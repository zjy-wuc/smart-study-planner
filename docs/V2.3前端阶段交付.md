# Smart Study Planner V2.3 前端阶段交付

## 已完成

- 新增 `/focus` 专注自习室并加入 WorkspaceShell 导航。
- 接入现有 Focus 会话接口，包括开始、同步、暂停、继续、结束并记录、放弃和历史查询。
- 支持 POMODORO 倒计时与 STOPWATCH 正计时，显示时间基于后端时间字段与本地时间差，不按 `setInterval` 次数累加。
- 页面重新可见、窗口重新获得焦点及计时达到目标时会调用同步接口，恢复或补结算活动会话。
- 支持关联 ACTIVE 计划及其有效任务，切换计划会清空旧任务选择。
- 支持环境声、音量本地保存、网页内沉浸模式、完成总结、可调整的 5/15 分钟休息计时和单次成果图片导出。
- 专注页展示后端真实的今日专注概览和最近三条记录。
- `/plans` 保留三列卡片和浅蓝山峦背景，新增计划概览、状态筛选、排序和按状态变化的主操作。
- 计划进度继续使用原有 `/plans/{id}/progress` 结果，只在 ACTIVE 卡片展示。
- `/statistics` 新增打卡统计、计划坚持、专注统计三个分类。
- 打卡统计保留原有日历和折线图。
- 专注统计接入 `/focus/statistics?days=7|30`，展示有效时长、参与次数、完整番茄钟和每日时长柱状图。
- 所有新增界面文案集中在 `messages/zh-CN`，新增样式放在 `components/css`。

## 暂未完成及后端接口缺口

### 统一学习历史

当前后端只有逐任务打卡记录接口和独立 Focus 分页接口。前端不能把两个接口的第一页简单拼接后冒充全局分页，因此本阶段没有改写现有 `/history` 数据源。

建议新增：

```text
GET /history?type=ALL|CHECKIN|FOCUS&page=1&page_size=20
```

建议响应：

```json
{
  "items": [
    {
      "id": "CHECKIN:123",
      "activity_type": "BOOLEAN_CHECKIN | NUMERIC_CHECKIN | POMODORO | STOPWATCH",
      "status": "COMPLETED | CANCELLED",
      "occurred_at": "2026-11-18T14:30:00",
      "focused_seconds": null,
      "recorded_value": 10,
      "plan_id": 1,
      "plan_name": "高等数学",
      "task_id": 2,
      "task_name": "完成习题"
    }
  ],
  "total": 1,
  "page": 1,
  "page_size": 20
}
```

后端必须按北京时间发生时间完成跨表全局排序和分页。

### 计划坚持统计

当前统计接口只返回打卡总数和 ACTIVE / ENDED 计划数量，没有计划级执行天数、执行覆盖率、最近执行时间和日期格数据。前端目前只展示真实计划数量及缺口说明，没有拉取大量任务历史在浏览器聚合。

建议新增：

```text
GET /statistics/plan-consistency?days=7|30
```

建议响应：

```json
{
  "days": 7,
  "as_of_date": "2026-11-18",
  "summary": {
    "active_count": 2,
    "ended_count": 3,
    "execution_days": 5
  },
  "plans": [
    {
      "plan_id": 1,
      "plan_name": "高等数学",
      "status": "ACTIVE",
      "execution_days": 4,
      "coverage_percent": 80.0,
      "last_recorded_at": "2026-11-18T09:30:00",
      "progress_percent": 42.5,
      "daily": [
        { "date": "2026-11-18", "checked_in": true }
      ]
    }
  ]
}
```

覆盖率分母为 0 时 `coverage_percent` 返回 `null`。ENDED 计划的 `progress_percent` 可以返回 `null`，不能以结束状态推断完成率。
