## 引用处理

- 路由、Service、后台到期检查进程和测试均改用完整的新模块路径。
- 同步修改 unittest.mock.patch 的字符串目标，保留原函数名和调用参数。
- 新建业务目录增加 __init__.py；不在包入口集中导入业务模块，避免不必要的循环依赖。
- statistics 已有目录保持原样；api/routes、schemas、core、jobs 入口保持原位置。
- 两份已有业务指南同步文件路径，移动文件的旧行号链接改为文件链接，避免跳到错误位置。
- 未提供旧路径转发文件；项目外脚本如使用旧模块路径，需要按上表更新。

- 应用全部 59 个非 __init__ Python 模块实际导入成功，包括后台任务模块。
