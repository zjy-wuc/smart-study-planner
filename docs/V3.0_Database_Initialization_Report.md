## 5. 隔离库预演过程与结果

1. 使用 `seed_demo.py --reset` 初始化，全部一致性检查为 0：
   - 任务越界、步骤归属、丢失打卡、数值进度不一致、超额、顺延不匹配、重复数值任务、笔记归属、今日 AI 请求、每日限额、笔记过短、审计标识、特殊账号封禁均为 0。
2. 创建 2 个额外“真实用户模拟样本”：
   - `real_sample`：独立计划 / 步骤 / 任务 / 记录 / 笔记各 1；
   - `real_dep`：笔记引用某个 demo 用户的计划，模拟真实数据依赖。
3. 清理预览：识别依赖，保护 `demo_01`，仅计划清理其余 28 个演示用户；真实样本不受影响。
4. 清理执行：删除 28 个演示用户及其业务数据，审计 `[DEMO]` 清零；`admin`、`REED`、`real_sample`、`real_dep` 全部保留，真实样本数据完整，受保护的 `demo_01` 及其计划保留。
5. 解除人工依赖后执行 `--include-special-study-data`：演示用户与 admin/REED 的预置学习数据被清理，两个特殊账号仍保留且启用；真实样本数据完整。
6. 通过 `init_production_demo.py --rehearsal --reset` 重新初始化，数据规模与一致性检查恢复到上述标准。
7. 特殊账号登录验证通过（HTTP 200，角色正确）。

## 7. 清理脚本行为

```powershell
# 默认只预览，不删除
$env:DB_NAME='smart_study_planner'
python scripts/cleanup_demo_data.py --manifest D:\ssp_seed_manifests\<清单>.json --allow-production

# 确认后执行（保留 admin / REED 及其学习数据）
python scripts/cleanup_demo_data.py --manifest D:\ssp_seed_manifests\<清单>.json --allow-production --execute

# 可选：同时清理 admin / REED 的预置学习数据（保留账号）
python scripts/cleanup_demo_data.py --manifest D:\ssp_seed_manifests\<清单>.json --allow-production --include-special-study-data --execute
```

- 正式库执行还要求环境变量 `SSP_CONFIRM_PRODUCTION_CLEANUP=YES`。
- 只按 `demo_` 用户名、Manifest 主键与 `[DEMO]` 审计定位数据；所有 DELETE 均带 WHERE，禁止 TRUNCATE 与无条件 DELETE。
- 清理前检查真实用户的笔记、专注、练习、AI 请求是否引用演示/特殊账号数据；存在依赖时保留相关记录并报告，不级联误删。
- `admin` / `REED` 账号永久保留；其学习数据需显式开关。
- 执行后核对真实用户数量、特殊账号数量与受保护用户数量，全部一致才报告成功。
