
# 智能学习计划管理系统 — 页面原型设计

## 一、页面 A：登录页

### 页面元素
- 系统名称：智能学习计划管理系统
- 用户名输入框
- 密码输入框
- 登录按钮
- 登录错误提示区域

### 交互
1. 用户填写账号和密码。
2. 点击登录。
3. 成功后进入首页；失败时显示错误提示。
4. 当前阶段只设计交互流程，后续再实现真实身份验证。

## 二、页面 B：首页

### 页面布局
- 顶部：系统名称、用户信息
- 左侧：导航栏
- 主区域：学习概览、今日任务、计划列表

### 核心功能
1. 创建新的学习计划。
2. 查看已有学习计划。
3. 查看今日待完成任务。
4. 查看计划总体进度。
5. 点击计划进入详情页。

### 页面状态
- 没有计划时，显示空状态和创建计划入口。
- 有计划时，展示计划列表。
- 今日任务为空时，提示暂无任务。

## 三、页面 C：计划详情 / 任务管理

### 页面布局
- 顶部：计划名称、计划目标、计划状态
- 中间：子计划列表
- 下方：每日任务列表
- 页面操作区：新增子计划、新增每日任务

### 核心功能
1. 查看大计划的目标和当前进度。
2. 创建子计划。
3. 创建子计划时，可以继续细分，也可以直接编写每日任务。
4. 新增、编辑、删除每日任务。
5. 将任务标记为已完成或未完成。
6. 对于需要量化的任务，记录目标值和当前值。
7. 查看计划及任务的完成情况。

### 任务类型
- 布尔型任务：例如完成一次 Java 知识点复习，记录是否完成。
- 数值型任务：例如学习 30 个单词，记录目标值和当前值。

### 进度规则
- 布尔型任务：完成时计为 100%，未完成时计为 0%。
- 数值型任务：根据当前值与目标值计算完成比例。
- 目标值必须大于 0；完成比例最多显示为 100%。
- 没有任务时显示“暂无任务”，不进行除零计算。

## 四、页面间的导航关系

登录页 → 首页 → 计划详情页

计划详情页支持返回首页。

1. 先明确页面结构和交互，不追求视觉精美。
2. 页面中的示例数据不等于真实数据库数据。
3. 今日必须完成原型设计；后续再逐步实现业务逻辑。
